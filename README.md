# Citas de Pasaportes

Página web estática para agendar citas de pasaportes (demostración).

## Cómo usarla

1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en cualquier navegador.

## Características

- Formulario de cita con validaciones
- Oficinas de todos los estados de México
- Generación de folio de confirmación
- Diseño responsive
